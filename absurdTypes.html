Nominal vs Min

Nominal: Target ceiling quantity of an item in the world. (There is NO <max> tag for item counts in DayZ; nominal IS the max ceiling).

Min: The floor threshold. When current world count drops below Min, the server spawns more until reaching Nominal.

Fatal min > nominal Loop

When min is higher than nominal (e.g. min 4,750 vs nominal 3,600):

1. Count (3600) < Min (4750) → Force spawn loot.

2. Ceiling is 3600 → Server cannot exceed 3600.

3. Loop runs every tick infinitely → Server FPS crashes.

QuantMin & QuantMax

Defines the percentage (0% to 100%) of internal capacity/ammo/water an item spawns with. E.g. 20% to 80% full.

Value -1: Disables quantity system for items without capacity (e.g. tools/keycards).
